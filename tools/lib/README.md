# tools/lib

`kahlua-j2se.jar` is Kahlua2 (MIT, Kristofer Karlsson) built so LuaRun
can load the shipped modules when `projectzomboid.jar` is not on the
machine. Same `se.krka.kahlua` classes the game vendors. Double
arithmetic is the engine's ([B48]). `--engine` still needs the game
jar. `KAHLUA-LICENSE.txt` is the upstream licence.
