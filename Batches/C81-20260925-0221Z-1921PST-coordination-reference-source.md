C81 supplies a reproducible source family for the first learned coordination
response experiment. The source catalogue declares twenty synthetic starting
situations and assigns each independent lineage to train, validation or test
before execution. It contains no expected response field.

Each run raises a concrete food-delivery matter, uses Communication and
Perception to establish actual reception, asks the shipped Controller to
appraise it, and captures Organization's decision-time evidence before the
actual return channel. Production forms four each of accept, qualify,
counter-propose, defer and contest. Every observed response occurs in every
partition. Decline and withdrawal remain implemented process responses but are
not represented by this source family.

Survivors use `SAO.Controller`. Afflicted and Crossed keep distinct pathogen
audit state while both resolve the retained human shell, current work,
capability and competing pressure through the registered ZAO adapter and
`ZAO.Driver`. The task-facing private appraisal carries generic pressure and
its source owner, not terminal state, diagnosis, diet or another actor's state.
This preserves their distinct state owners without making either a separate
controller or treating them as equivalent behavior.

Border 191 reruns all twenty situations and compares the tracked artifacts byte
for byte. Its controls alter the Controller's pressure decision, remove ZAO's
execution registration and forge the Driver attribution; all three change or
invalidate the expected evidence. Border 159 separately isolates the dormant
joint loader. It now requires shared `ZAO_Maintenance` and recognizes
`ZAO.Driver` as a loaded-body owner that is deliberately absent from dormant
county execution.

Source hashes cover the exact Git index blobs after working-copy agreement is
checked, so an immutable SAO or ZAO commit reproduces them even when the local
checkout materializes different line endings.

runtime, launch the game or establish loaded-world behavior. Speakeasy owns the
independent review, bounded admission, reference training and held-out report.
