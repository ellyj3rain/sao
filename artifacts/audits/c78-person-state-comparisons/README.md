# Person-state capture evidence

`captures-v2/` contains five immutable captures and producer manifests generated
by `tools/conversation_evidence.py --scenario NAME --out NEW_DIRECTORY`.
Each runs the production owners in installed Kahlua over declared authored
inputs. Names are baseline, trusted, threat, learned and strain.

All share the same person, listener, question and acquired July 2 report.
Their manifests describe exact interventions and the shared controlled
neurological observation interval. These are not sampled play sessions.
Version 2 binds detached behavioral channels inside the capture identity;
original version-1 exports remain supported.

The scenario set exercises source differences. Candidate response preferences
belong to Speakeasy and require actual operator review. It supplies no trained
speaker, complete action alternatives, or loaded native-state evidence.

Validation runs through Border 189's existing gate entry. Source review found
empty trait-channel acceptance and future threat time; both now refuse. The
direct reader also refuses nonfinite threat times. A real source mutation of
the trait contribution writer is detected. Loaded reader tests use explicitly
controlled boundary objects and remain separate from this bodyless family.
