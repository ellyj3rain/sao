/* PLAYTEST 2026-09-16. Every default below reproduces the value that was
   hardcoded before this option existed, so an existing save or server that
   never touches these behaves exactly as it always has. Values are read
   fresh on every use (K.sandbox), server-authoritative for anything that
   decides what a player may do (KA_Core / KA_Server), never trusted from a
   client alone. This file is parsed by the same script parser vanilla's own
   scripts use, which strips C-style block comments like this one - a Lua
   line comment would not be recognised, so none is used here. */
